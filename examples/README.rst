.. _examples:

Examples
========

A gallery of examples. Each example is a complete FElupe-script with a contact of felupe-contact: a rubber body is pressed on a bigger body. The examples differ in the definition of the contact surfaces, in the dimension of the problem, in the type of the cells and in the friction. Coarse meshes are used whenever possible to make the examples run fast.

The building blocks of the examples are explained step by step in the :ref:`getting-started` guide.
